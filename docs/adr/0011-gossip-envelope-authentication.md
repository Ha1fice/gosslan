# ADR-0011：Gossip 信封完整性与身份绑定

## 状态

已采用（0.12.x Unreleased）

## 背景

旧实现只对 `message_id` 签名，而 `message_id` 只由发送者 ID、时间戳和载荷计算。攻击者可以复用有效签名篡改 `kind`、群成员快照或公钥字段；同时，信封内自报的设备 ID 与 Ed25519 公钥没有绑定关系。

## 决策

- Gossip 签名材料绑定发送者、公钥、消息类型、群元数据、载荷、时间戳和加密标志；TTL 不签名，因为中继转发时必须递减。
- 接收方只信任已由 Discovery/Hello 绑定到同一 `device_id` 的公钥。直连 TCP 对端首次发送 Gossip 时允许一次 TOFU，之后必须匹配已绑定的密钥。
- 不新增 JSON 字段；旧版本生成的仅签 `message_id` 的 Gossip 信封不再通过新版本验签。

## 结果

消息元数据不可被中继节点静默改写，伪造设备也不能借用真实设备 ID 写入单聊或群聊。升级期间旧版本与新版本之间的 Gossip 互通会受限；直连 ChatMessage 和好友流程不受此签名格式变化影响。
